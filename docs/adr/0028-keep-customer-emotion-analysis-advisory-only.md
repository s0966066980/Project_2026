# Keep customer emotion analysis advisory-only

Customer emotion analysis produces observations and staff-facing Customer Emotion Advisory only. It never changes voice responses, recommendations, prices, or ordering behavior automatically, so the previous off/shadow/active intervention modes, confidence gate, rollout percentage, and `EMOTION_AFFECT_VOICE` path are removed; capture timing is governed instead by the mutually exclusive Customer Emotion Analysis Mode. This favors explainable customer-service reference over automated behavioral intervention.
