# Require offline acceptance before concrete optimization guidance

Status: accepted

Observation Signals may appear without candidate execution, but concrete Prompt, model, or RAG Reference Guidance requires an Offline Optimization Evaluation in an isolated non-production environment. Voice candidates must preserve structured JSON, menu-ID allowlisting, no false order-confirmation claim, Traditional Chinese output, and TTS-safe text. RAG candidates must pass answerable and unanswerable queries, source correspondence, and non-fabrication checks.

A candidate that regresses any existing safety acceptance is rejected even when it improves the triggering examples. If evaluation cannot run, the report labels the direction Unverified and may describe only the suspected seam and next test; it omits directly reusable settings values, prompt text, and knowledge content. Evaluation results remain reference-only and grant no production authority.
