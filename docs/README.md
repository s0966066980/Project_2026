# docs 模組說明

`docs/` 保存版本化架構決策、商業化治理與後續模組規劃。

## 文件規則

- 各模組說明放在自己的 `README.md`。
- 架構現況與目標放在 `architecture/`。
- 商業化 roadmap、risk 與 migration plan 放在 `commercialization/`。
- 一般後續改善項目集中在 `FUTURE_MODULES.md`。
- 若規劃已實作，應同步更新對應模組 README。
- 不再新增零散的 code review、roadmap、changelog markdown。

## 目前文件

- [FUTURE_MODULES.md](FUTURE_MODULES.md)：後續可改善例子與可新增模組。
- [CURRENT_STATE.md](architecture/CURRENT_STATE.md)：實際程式碼架構基線。
- [TARGET_ARCHITECTURE.md](architecture/TARGET_ARCHITECTURE.md)：分階段目標架構。
- [ROADMAP.md](commercialization/ROADMAP.md)：商業化 Milestone 與 exit criteria。
- [RISK_REGISTER.md](commercialization/RISK_REGISTER.md)：風險、優先級與緩解計畫。
- [MEMBER_MIGRATION_PLAN.md](commercialization/MEMBER_MIGRATION_PLAN.md)：會員 UUID/PII 相容遷移策略。
