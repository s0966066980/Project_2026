推論服務狀態

Emotion-LLaMA 後端

開啟後在事件觸發或週期模式中使用 Emotion-LLaMA 進行情緒分析。需先啟動 Emotion-LLaMA Gradio 服務。

偵測鏡頭（YOLO）

開啟後 POS 左上角顯示偵測鏡頭；開始點餐後會先偵測顧客，再啟用語音協助。

影響 AI 推播

開啟後，推薦餐點會參考 Emotion-LLaMA 的情緒標籤、判斷依據與分佈；關閉後只依菜單、歷史點餐與 RAG 規則推薦。
