檢查模型
  1. 先確認選定模型已載入且宣告 video_audio 能力。
  2. 允許攝影機與麥克風，按下開始後說出一句測試內容；停頓時自動結束。

  4. 畫面分開顯示模型分類、模型分析內容、STT 狀態與不改分類的 LLM 解說。
  5. 回應完成後關閉裝置並刪除原始影音與逐字稿，只留下有界診斷紀錄。
