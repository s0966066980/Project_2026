4. 自主修正 Loop
======================================================================

DISCOVER
→ BASELINE
→ PLAN
→ CHANGE
→ FAST TEST
→ DIAGNOSE
→ FIX
→ FAST TEST
→ MILESTONE TEST
→ REVIEW
→ COMMIT
→ CONTINUE

規則：

- Fast Gate 最多修正 5 輪。
- Milestone Gate 最多修正 5 輪。
- 同一錯誤連續兩次沒有新資訊時，改用最小重現、單檔測試或 Debug Log。
- 同一錯誤連續三次時，重新檢查設計假設。
- 第五次仍失敗，標 BLOCKED_INTERNAL。
- 不得只重跑相同命令。
- 不得刪除真正抓到 Bug 的 Regression Test。

禁止手段：

- 空測試
- 無理由 skip / xfail
- except Exception: pass
- 放寬 Scope/Auth/Security
- 把 Integration 改成全 Mock
- No-op Side Effect
- 用 sleep 掩蓋 Race
